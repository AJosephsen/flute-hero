# Moonlit UI kit

Hand-authored SVG assets for the buildable moonlit classroom interface.

These are deliberately simple and crisp so the game UI can stay responsive and editable in CSS/Canvas instead of depending on fuzzy generated UI art.

## Assets

- `raccoon-mascot.svg` — hero mascot / future guide character.
- `recorder-icon.svg` — recorder/flute affordance for buttons and song cards.
- `star-badge.svg` — success/reward badge.
- `moon-playhead.svg` — reference shape for the Canvas playhead.
- `note-node.svg` — reference shape for note starts and pitch targets.

## Direction

Use generated PNGs for atmosphere/backgrounds. Use SVG/CSS/Canvas for gameplay-critical UI: lanes, notes, playhead, hit feedback, controls.
